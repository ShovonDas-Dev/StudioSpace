## ✨ About The Project

**StudioSpace** is a modern studio-booking platform designed to connect creative professionals with inspiring spaces.

Users can explore studios for photography, filmmaking, podcasting, music production, and content creation.

The platform provides an easy way for creators to discover creative spaces and for studio owners to showcase and manage their listings.

## 🚀 Features

- Discover creative studio spaces.
- Explore studios by category.
- View studio details and equipment.
- Studio listing management for hosts.
- User authentication.
- Booking request experience.
- Responsive design for all devices.
- Modern and user-friendly interface.

## 💻 Installation & Setup

### Prerequisites

- Node.js
- npm
- Git

```bash

```

### 2. Navigate to Project

```bash

```

### 3. Install Dependencies

```bash

```

### 4. Configure Environment Variables
